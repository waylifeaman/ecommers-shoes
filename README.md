#Website e-commers

Aplikasi ecommers sederhana dengan sistem login dan registrasi, terdapat fitur add to chart
dibaut dengan HTML Css dan javascript dan memanfaatka restfull api express.js, dan MySql untuk databasenya

**Demo:** https://ecommers-shoes-ust5.vercel.app/features/auth/login.html

---
##Fitur
- Login
- Registrasi
- Home : halaman menampiilkan halaman dashbord yang terdapat jumbotron dan ada beberapa produk.
- Produk : halaman menampilkan semua produk, terdapat fitur tab bar untuk menampilkan produk susuai kategori
- Search Bar : menu searchbar untuk mencari  produk
- Detail Produk : menampilkan produk detail produk dan terdapat fitur checkout dan add to chart
